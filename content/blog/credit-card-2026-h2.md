## 前言

2026 已經來到下半年，講到這半年的回饋神卡，一定有這三張：

<u>**國泰世華 CUBE 卡、台新 Richart 卡、永豐 DAWHO 現金回饋卡**</u>

本來手上就有 CUBE 跟 DAWHO 兩張信用卡，觀望了一陣子之後，也在近期申辦了台新 Richart 卡。辦了之後才發現，CUBE 共 8 個回饋方案（扣除爸媽專屬方案）可以切換，Richart 更有 9 個，光是結帳時思考要用哪張卡、選哪個方案就頭昏眼花 😵‍💫。基於自己的問題自己研究的精神，趁著空閒時間詳細拆分比較了一番，也在這邊分享出來，供大家參考。

先講結論：==日常小額刷 DAWHO，網購、旅遊、餐廳、百貨公司大額優先刷 Richart，若當日方案衝突，再改刷 CUBE== [^1]

以下詳細展開。

## 永豐 DAWHO 回饋

首先來聊最不需要思考的 DAWHO 卡。DAWHO 卡的強項在於不綁通路，在一定消費額度內可以達到 3.5 %，甚至 5 % 的回饋趴數。

![DAWHO分級](/img/dawho.png)

_資料來源：[永豐銀行](https://bank.sinopac.com/sinopacBT/personal/credit-card/introduction/bankcard/DAWHO.html)_

`大戶` 等級的門檻不算太高：只要每個月有一筆台股成交，或是 5000 元以上換匯紀錄就可以升等；如果有存款需求，也可以透過在帳戶存放 30 萬來升等。

`大戶 Plus` 等級就沒這麼輕鬆了：除了台股成交或是換匯紀錄，還要求 100 萬元的存款，對小資族而言是不小的門檻。

換算回饋上限，`大戶` 等級每個月刷 11,428 元以內都享有 3.5 % 回饋，`大戶 Plus` 等級則是 20,000 元以內都享有 5 % 回饋。所以如果沒有閒錢的話，其實可以選擇維持 `大戶` 等級就好，會是 CP 值比較高的選擇～

## 國泰世華 CUBE 方案一覽

方案與對應通路太多，就不一一貼圖了，以下重點整理：

| 方案     | 通路類型                                    | 趴數          | 限制             |
| -------- | ------------------------------------------- | ------------- | ---------------- |
| 固定回饋 | 一般消費 / 海外實體                         | 1.2 % / 2.5 % | 不含保費         |
| 台塑家   | 加油、保健、超商                            | 2 %           | -                |
| 全支付   | 全聯、全支付                                | 2 %           | -                |
| 集精選   | 充電停車、量販、加油、超商、家居            | 2 %           | -                |
| 玩數位   | 訂閱、AI 工具、網購                         | 3 %           | -                |
| 樂饗購   | 百貨、外送、餐飲、藥妝                      | 3 %           | -                |
| 趣旅行   | 海外實體、交通、航空、住宿、訂房            | 3 %           | -                |
| 慶生月   | 購物（3.5 %）<br>指定餐廳、樂園娛樂（10 %） | 3.5 % / 10 %  | 限定生日當月使用 |

_資料來源：[國泰世華銀行](https://www.cathay-cube.com.tw/cathaybk/personal/product/credit-card/cards/cube-list)_

可以發現到，前四個方案除了趴數低，單筆消費通常也不會太高（都是日常小筆開銷）。DAWHO 的 3.5 % 額度平均分攤到每一天，一天也還有 300 多元的空間，足以應付這類日常小額消費。既然如此，直接刷 DAWHO 不但趴數更高，也不會白白把 CUBE 當天的方案額度用掉。

在討論後四個方案前，先看台新 Richart 的回饋方案。

## 台新 Richart 方案一覽

一樣先上重點整理：

| 方案     | 通路類型                                                                 | 趴數          | 限制        |
| -------- | ------------------------------------------------------------------------ | ------------- | ----------- |
| 保費     | 一次付清保費                                                             | 1.3 %         | -           |
| 假日刷   | 國內假日不限通路                                                         | 2 %           | -           |
| Pay 著刷 | LINE Pay、全盈 +Pay（2.3 %）<br>台新 Pay（3.8 %）                        | 2.3 % / 3.8 % | -           |
| 天天刷   | 超商、超市、交通、停車加油、藥妝                                         | 3.3 %         | -           |
| 大筆刷   | 百貨、Outlet、居家裝修、時尚品牌                                         | 3.3 %         | -           |
| 好饗刷   | 餐飲、外送、購票娛樂、飯店、KTV                                          | 3.3 %         | -           |
| 數趣刷   | 網購、線上課程、遊戲影音、AI 服務                                        | 3.3 %         | -           |
| 玩旅刷   | 海外消費、航空、海外交通、訂房、旅行社                                   | 3.3 %         | -           |
| Chill 刷 | 數位服務（3.3 %）<br>追星串流、運動保健（5 %）<br>火鍋燒肉、飲品（10 %） | 3.3 % ~ 10 %  | 活動到 9/30 |

_資料來源：[台新銀行](https://mkp.taishinbank.com.tw/TsCms/marketing/expose/WM_20260708095300794/index.html)_

不難發現，Richart 的方案結構跟 CUBE 幾乎是同一套邏輯：不限通路的方案趴數偏低，主力方案則綁定特定通路類型。差別在於 Richart 的主力方案硬是比 CUBE 多了 0.3 %，涵蓋的商家也更廣！但代價是 Richart 把通路切得更零碎，具體對應關係如下：

```
玩數位 -> 數趣刷
樂饗購 -> 大筆刷（百貨購物）、好饗刷（餐飲）
趣旅行 -> 天天刷（高鐵、計程車）、玩旅刷（機票、訂房平台）
```

所以，對於高額的購物、旅遊、聚餐開銷，優先刷 Richart 卡，CUBE 卡則可以當作方案額度用掉之後的備案。
